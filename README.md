# 🏥 Hospital Management System

A simple **Hospital Management System** built using **Python and MySQL**.  
The project provides a menu-driven interface to manage hospital records directly from a MySQL database. 🩺💻

## ✨ Features

- 👨‍⚕️ Manage doctors
- 🧑‍🤝‍🧑 Manage patients
- 👩‍⚕️ Manage nurses
- 🏠 Manage hospital rooms
- 💰 Manage bills
- 🧪 Manage test reports
- 📋 Manage hospital records
- 🔗 Manage relationships between tables
- 🔍 Search records
- ➕ Insert records
- ✏️ Update records
- 🗑️ Delete records
- 👀 View table data
- 💻 Run custom SQL `SELECT` queries

## 🛠️ Technologies Used

- 🐍 Python
- 🐬 MySQL
- 🔌 MySQL Connector/Python
