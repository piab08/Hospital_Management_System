🏥 Hospital Management DBMS
A Hospital Management Database Management System designed to efficiently manage hospital records and operations.

✨ Features
👨‍⚕️ Doctor & Patient Management

📅 Appointment Management

🏨 Room & Admission Management

💊 Prescription & Medicine Management

🧪 Medical Test Management

💰 Billing Management

🗄️ SQL Queries, Joins, Views, Procedures & Triggers

🛠️ Technologies
🐬 MySQL

💻 SQL

🖥️ MySQL Workbench

📌 Purpose
An academic DBMS project demonstrating database design, relationships, normalization, and SQL concepts in a hospital management system.
